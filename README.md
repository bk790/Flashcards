# Introduction to AI – Flashcards

Mobile-friendly static flashcard website.

## Deploy on GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for the published website link in the Pages section.

## Included
- Module filters, reveal answer, previous/next, shuffle.
- Mark cards as known or needing revision.
- Local browser progress tracking.

**Content note:** This package contains the 30 question-answer pairs available in the saved deck details. The saved deck contains 40 cards, but the other 10 card contents were not available in the current context.
